# T-021 Blender 装机与部件拆分管线（转盘/暗门 parts GLB）

- 摘要: Blender 4.2.23 LTS 装机（winget 403→南大镜像 portable zip，.dsh/tools/blender）+ split_parts.py 拆分管线：join+remove_doubles(1mm) 焊点修复量化碎片爆炸（1906→10 连通体），按体积排序 body+pointer 导出。三转盘全产出 body（dial_2 走 SINGLE_PART 分支，三脚本路径全验证）；pointer 碎片跨度过大弃用，动画改盘体整体旋转（第一性原理：不多加）
- 改动文件:
  - pipeline/blender/README.md
  - pipeline/blender/split_parts.py
  - demo/public/models/parts/obj_basement_dial_1_body.glb
  - demo/public/models/parts/obj_basement_dial_1_pointer.glb

  - demo/public/models/parts/obj_basement_dial_3_body.glb

- 验收命令与结果:
  - `blender --version`（portable 路径调用）→ **Blender 4.2.23 LTS**（build 2026-07-21）
  - `blender --background --python split_parts.py -- --input obj_basement_dial_1.glb ...` → 首跑暴露量化碎片问题（loose parts 1906 个）；脚本加 join+remove_doubles(threshold=0.001) 后 → **10 连通体**，body=0.30×0.05×0.30 盘体（1.57MB）+ pointer=152KB 碎件
  - dial_2 → SINGLE_PART 分支（整件 body）；dial_3 → body+pointer；三脚本路径（多件/单件/无 pointer）全验证
  - bbox 复核：body 尺寸与原 dial GLB 一致（0.30 盘径），无变形
  - build ✅ + 27/27 单测 ✅（T-011 同批验证，见其交接单）
- 风险/未完成:
  - **暗门未拆**：bpy 拆分聚焦转盘示范；暗门（obj_basement_secret_door）雕刻一体大概率 SINGLE_PART，且其动画（开合）更适合 R3F 整体绕门轴 rotation——建议 T-011 后续以 R3F 层处理，不强行 Blender 拆
  - pointer 碎件（dial_1/dial_3）为罗马数字等浮游雕花合集，跨度大不能作旋转指针；保留在 parts/ 未接线（未来细化可按聚类再分）
  - Blender 为 portable（.dsh/tools/），不在 PATH；调用用全路径（pipeline/blender/README.md 有命令）
