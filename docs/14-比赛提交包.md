## 1. 一页纸项目说明（报告书核心）

**《提灯与暗门》(The Lantern and the Hidden Door)** —— 由 Aholo Lux3D 真实资产驱动的第一人称 3D 叙事空间：雨夜书房醒来 → 找到提灯 → 下行地下室 → 解开三符号转盘机关 → 密室结局 → **进入 SpatialGen 生成的 3DGS「记忆回廊」**。

**技术链（全程真实跑通）**：
```
Lux3D 两段式生成（文生图 G1-Turbo → 图生3D G1，17/17 件，官方任务号 4625608-4657113 可审计）
→ Blender 4.2 headless 修整/部件拆分（bpy 管线）
→ gltf-transform 压缩（quantize+simplify+WebP，raw 9.5MB→1.2MB，-89%）
→ Three.js/R3F + Zustand 运行时（applyAction 纯函数状态机，27/27 单测即契约）
→ FastAPI + PostgreSQL/pgvector（mock 13/13 E2E；pg 库 HNSW 向量检索回路实测通过）
```

**验收基线（全部实测）**：build ✓ 6.8s · 单测 27/27 · 17 件 GLB 全部 HTTP 200 `model/gltf-binary`（1.0-3.2MB/件）· 生产部署日志零 WARN/ERROR · 密钥零落盘（四模式扫描 CLEAN）。

## 5. 90 秒视频脚本（分镜表，真人录屏用）

> 录法：桌面 Chrome 全屏录屏（Win+G 或 OBS），鼠标操作，节奏按秒数走。**前 10 秒决定评委停留。**

| 秒 | 画面 | 操作/字幕 |
|---|---|---|
| 0-8 | 书房暗调开场，镜头缓推书桌 | 字幕：雨夜，一间不该出现的书房（环境音=游戏内置雨声） |
| 8-14 | **提灯高光**：按 L 点灯，暖光漫开，地板暗门缝隙浮现 | 字幕：Aholo Lux3D 生成的每一件物件 |
| 14-22 | 开地板门下行，地下室滴水声+提灯照亮浮雕三符号 | 字幕：17 件 AI 资产 · 管线压缩 -89% |
| 22-34 | 拨转盘 3→1→2（特写盘体转动），错序一次→震动重置→正确→暗门开 | 字幕：数据驱动的机关状态机 |
| 34-44 | 进密室，石台册子，结局面板 | 字幕：27 项单测守护的七步主线 |
| 44-56 | 点「进入记忆回廊」→ 全景石室（拖动环视）→ 切实验模式 3DGS 点云 | 字幕：SpatialGen 3DGS · 上一任屋主的空间记忆 |
| 56-70 | 按 Tab 档案检索「提灯」→ 结果点击→镜头定位+高亮 | 字幕：空间化的知识检索 |
| 70-78 | 按 F 叙事 Agent 问答（引用条目+sources） | 字幕：受控 Agent · 只读不越权 |
| 78-90 | 标题定帧 | 字幕：《提灯与暗门》提灯与暗门 · Aholo Lux3D × SpatialGen × MCP（链接浮现） |
